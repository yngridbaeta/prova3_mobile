# ☕ App de Gerenciamento de Produtos

Este é um aplicativo com integração ao **Firebase Firestore**.  
O app possui uma interface simples, suporte a imagens via URL e atualizações em tempo real usando `StreamBuilder`.

---

## 🚀 Funcionalidades

- ➕ Adicionar produtos  
- ✏️ Editar produtos cadastrados  
- 🗑️ Excluir produtos 
- 📦 Listagem dos produto
- 🔥 Integração com Firebase  
- 🖼️ Tratamento de erro  
- 🎨 Interface estilizada com cores personalizadas  

---

## 📁 Tecnologias Utilizadas

- **Flutter**
- **Dart**
- **Firebase Core**
- **Cloud Firestore**
- **Material Design**
